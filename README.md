# FixMate

FixMate is a repair service booking platform where users can find technicians, book services, track their bookings, and pay online.

### Live Link
- Frontend: https://fixmate-client-puce.vercel.app
- Backend: https://fixmate-server-cyan.vercel.app

### Features
- Browse and book repair services
- Manage services and bookings
- Admin dashboard
- User role management
- Online payment with Stripe
- Booking status tracking

### Tech Stack
Next.js, TypeScript, Tailwind CSS, Express.js, MongoDB, Better Auth, JWT, Stripe.

### Installation

npm install
npm run dev
